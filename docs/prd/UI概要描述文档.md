# StudySmart 插件UI设计与交互描述

本文档基于《需求草稿.md》，旨在为UI/UX设计师和开发人员提供清晰的界面设计和交互流程指导。

## 1. 核心设计理念

*   **简洁高效**：核心操作路径（选中文本 -> 生成卡片 -> 保存）必须尽可能短，减少用户点击次数。
*   **情境感知**：UI元素（如悬浮按钮）应在用户需要时才出现，不干扰正常浏览。
*   **灵活强大**：为普通用户提供开箱即用的体验，同时为高级用户提供深度定制（自定义Prompt）的入口。

---

## 2. 主要界面组件

插件的UI主要由以下几个部分构成：

1.  **悬浮工具栏 (Floating Toolbar)**：在用户选中文本后，动态出现的交互入口。
2.  **卡片生成面板 (Generation Panel)**：处理文本、调用GPT并展示结果的核心交互界面。
3.  **侧边栏 (Sidebar)**：用户的个人卡片库，用于管理和导出所有已保存的卡片。
4.  **设置页面 (Settings Page)**：用于配置API Key、管理Prompt和设置导出选项。

---

## 3. 交互流程详解

### 3.1 流程一：从选中内容到生成卡片

这是最核心的用户旅程，现在以悬浮工具栏为起点。

#### **步骤1：触发**

用户在网页上选定一段文本后，系统会立即在选区附近（通常是上方或下方）弹出一个小巧的悬浮工具栏。

*   **外观**：一个横向的、圆角的工具栏，背景色与页面内容有轻微区分，避免突兀。
*   **内容**：
    *   工具栏内包含一系列的按钮，每个按钮对应一个**已在设置中启用的Prompt**（例如：“生成闪卡”、“解释概念”、“翻译”、“语法分析”等）。
    *   按钮可以设计为“图标+文字”或仅“文字”的简洁形式。
    *   如果启用的Prompt过多，工具栏可以水平滚动，或者末尾提供一个“...”按钮，点击后以下拉菜单形式展示所有可用的Prompt。
*   **交互**：
    *   鼠标移出选区或点击页面其他地方，工具栏会自动消失。
    *   点击工具栏上的任意一个Prompt按钮（例如点击“解释概念”）。

#### **步骤2：卡片生成面板 (Modal/Popup)**

点击工具栏上的某个指令按钮后，浏览器右上角会弹出“卡片生成面板”。

*   **顶部区域 - 输入与指令**
    *   **来源文本**：一个只读文本框，显示用户刚刚选择的文本，并标注来源URL。
    *   **Prompt选择器**：一个下拉菜单，默认选项为“默认模板”。用户可以从中选择：
        *   插件预置的Prompt（如：词汇提取、语法分析、总结大意）。
        *   用户自己保存的自定义Prompt。
    *   **管理Prompt**：下拉菜单旁有一个“管理”按钮或齿轮图标，点击后会跳转到“自定义Prompt管理器”界面。

*   **中部区域 - 生成结果**
    *   **自动执行**：面板弹出后，应**立即使用选中的Prompt和文本调用GPT**，无需用户再次点击“生成”按钮。
    *   **加载状态**：此区域显示一个加载动画和提示性文本，如“AI正在努力思考中...”。
    *   **卡片建议列表**：GPT返回结果后，此区域会以列表形式展示所有建议的闪卡。
        *   **卡片预览**：每张建议的卡片都以“正面”和“背面”的形式清晰展示。如果内容过长，可以折叠显示。
        *   **选择框**：每张卡片左侧都有一个复选框，允许用户选择一张或多张希望保存的卡片。默认全部选中。
        *   **编辑功能**：每张卡片的“正面”和“背面”内容都应该是可直接点击编辑的文本区域，方便用户在保存前进行微调。
        *   **舍弃按钮**：在每张卡片的角落（如右上角）提供一个“x”图标按钮。点击后，该卡片将从本次的建议列表中被移除，方便用户在批量添加前排除不想要的内容。

*   **底部区域 - 操作**
    *   **全部添加**：一个主操作按钮，文字为“添加到卡片库”。点击后，所有**被勾选的**卡片将被保存。
    *   **错误提示**：如果API调用失败，此区域会显示清晰的错误信息（如“API Key无效或已过期，请检查设置”）。

### 3.2 流程二：管理与浏览已存卡片

#### **侧边栏 (Sidebar) - 卡片库**

用户可以通过点击浏览器工具栏上的插件图标来打开或关闭侧边栏，这里是所有卡片的管理中心。

*   **顶部控制区**
    *   **搜索框**：支持关键词搜索，可以实时过滤下方的卡片列表。
    *   **筛选器**：一个漏斗图标，点击后弹出菜单，可按“标签”、“来源URL”、“同步状态”（如：未同步、已同步、失败）进行筛选。
    *   **批量操作按钮**：当用户选中一张或多张卡片后，此处会出现“移动到...”和“删除”等批量操作按钮。
    *   **导出按钮**：点击后弹出“导出配置”窗口，执行导出任务。
    *   **新建集合**：一个“+”按钮，允许用户创建新的卡片集合（文件夹）。
*   **集合/分类列表 (左侧)**
    *   一个可折叠的树状列表，显示所有卡片集合。
    *   **收件箱 (Inbox)**：一个位于顶部的、固定的特殊集合，不可删除。所有新生成的卡片将**默认保存于此**，等待用户归类。
    *   **普通集合**：显示用户创建的各个集合（如“历史”、“计算机科学”）。列表底部有“+ 新建集合”按钮。

*   **卡片列表 (右侧主区域)**
    *   **视图**：以列表形式展示所有（或筛选后的）闪卡。
    *   **卡片条目**：
        *   **内容**：每个条目显示卡片的“正面”内容、几个关键“标签”和来源网站的favicon。
        *   **同步状态标识**：在卡片条目的显著位置（如标题右侧）会有一个图标，清晰地表明该卡片的同步状态：
            *   **待同步** (灰色云朵图标)：卡片已生成，但未导出到任何平台。
            *   **已同步** (绿色对勾图标)：卡片已成功导出。
            *   **同步失败** (红色警告图标)：上次尝试导出失败，悬浮可查看原因。
        *   **多选框**：每个卡片条目左侧都有一个复选框，用于批量选择。
    *   **交互**：
        *   **单击**：展开卡片，显示完整的“正面”、“背面”等所有信息。
        *   **悬浮**：在卡片条目上悬浮鼠标，右侧出现“编辑”和“删除”图标。
        *   **拖拽归类**：用户可以直接将一张或多张选中的卡片从右侧列表拖拽到左侧的目标集合中，完成快速归类。
        *   **右键菜单**：在卡片上右键可弹出快捷菜单，提供“移动到集合”、“立即同步”、“删除”等操作。

### 3.3 流程三：高级定制 - 自定义 Prompt

#### **自定义Prompt管理器**

此界面可以通过“卡片生成面板”的“管理”按钮或主“设置”页面进入。

*   **界面布局**：左侧是Prompt预设列表，右侧是选定Prompt的编辑区。
*   **Prompt列表 (左侧)**
    *   显示所有预置和用户自定义的Prompt名称。
    *   列表中的每一项前面都应有拖拽手柄（如六个点的图标），允许用户按住并上下拖动以调整其在悬浮工具栏和选择器中的顺序。
    *   提供“新建Prompt”按钮。
    *   每个Prompt名称旁有“删除”或“复制”图标。
*   **Prompt编辑区 (右侧)**
    *   **Prompt名称**：一个输入框，用于命名该Prompt（例如：“英语习语提取”）。这个名称会显示在悬浮工具栏的按钮上。
    *   **Prompt图标**：一个图标选择器。点击后弹出一个包含多种预设图标的面板，用户可以为该Prompt选择一个图标，用于在悬浮工具栏中显示。
    *   **在工具栏中显示**：一个开关（Switch/Checkbox）。用户可以决定此Prompt是否作为快捷指令出现在选中文本后的悬浮工具栏中。
    *   **Prompt内容**：一个大的文本域，用于编写Prompt指令。
    *   **占位符提示**：在文本域下方，清晰地列出所有可用的占位符及其含义，如：`{{selected_text}}` - 用户选择的文本。
    *   **操作按钮**：“保存”和“取消”。

### 3.4 流程四：导出与集成

此流程现在作为设置页面的一部分进行统一管理。

## 4. 设置页面 (Settings Page)

设置页面是插件所有配置的中心枢纽，采用清晰的导航结构（如左侧标签页导航），包含以下几个主要部分：

### 4.1 AI模型设置

此区域用于创建和管理多个AI模型配置，方便用户在不同提供商、模型或API Key之间快速切换。

*   **配置管理**:
    *   **配置文件选择器**: 一个下拉菜单，位于此区域的顶部，用于列出并选择所有已保存的配置（例如“公司用OpenAI”、“个人Gemini”）。
    *   **操作按钮**: 选择器旁边提供一组按钮，用于“新建配置”、“重命名当前配置”和“删除当前配置”。
*   **配置详情**:
    *   选择一个配置文件后，下方会显示其详细设置。
    *   **API提供商**: 一个下拉菜单，让用户选择该配置对应的厂商（如 OpenAI, Google Gemini, Groq, DeepSeek 等）。
    *   **API密钥**: 一个密码类型的输入框，用于输入所选厂商的API Key。输入框下应有提示，说明密钥被安全存储。
    *   **自定义基础URL (Base URL)**: 一个复选框，勾选后出现文本输入框，允许用户为该配置指定一个自定义的API端点，以支持代理或私有化部署。
    *   **模型**: 一个文本输入框或下拉菜单，用于指定要使用的具体模型名称（例如“gpt-4-turbo”或“gemini-1.5-pro-latest”）。
*   **激活配置**: 在下拉菜单中被选中的配置文件即为当前激活的配置，所有AI生成任务将默认使用该配置。

### 4.2 Prompt管理

此部分即为 `3.3 流程三` 中描述的 **自定义Prompt管理器**。它被整合到设置页面中，作为核心功能之一。

*   **Prompt列表 (左侧)**
    *   显示所有预置和用户自定义的Prompt名称。
    *   列表中的每一项前面都应有拖拽手柄（如六个点的图标），允许用户按住并上下拖动以调整其在悬浮工具栏和选择器中的顺序。
    *   提供“新建Prompt”按钮。
    *   每个Prompt名称旁有“删除”或“复制”图标。
*   **Prompt编辑区 (右侧)**
    *   **Prompt名称**：一个输入框。
    *   **Prompt图标**：一个图标选择器，让用户为Prompt关联一个图标。
    *   **在工具栏中显示**：开关控件。
    *   **Prompt内容**：大的文本域。
    *   **占位符提示**：文本域下方提供可用占位符列表。
    *   **操作按钮**：“保存”和“取消”。

### 4.3 导出平台设置

此区域用于配置与第三方学习平台（如Anki, RemNote）的集成。

*   **界面布局**：同样可以采用标签页设计，分别为Anki和RemNote提供独立的配置面板。
*   **Anki 设置**:
    *   **API URL**：AnkiConnect插件的API地址（通常是 `http://localhost:8765`）。
    *   **API Key**：AnkiConnect的可选API密钥。
    *   **字段映射**：提供一个动态的字段映射界面。
        *   当连接成功后，插件应能自动获取Anki中所有的笔记类型（Note Types）和字段（Fields）。
        *   用户可以选择一个笔记类型，然后插件会展示该类型下的所有字段。
        *   用户可以将插件内部的字段（如：正面、背面、标签、来源URL）通过下拉菜单的方式，映射到所选Anki笔记类型的对应字段上。
*   **RemNote 设置**:
    *   **API Key**：用户在RemNote中生成的API密钥。
    *   **User ID**：用户在RemNote中生成的User ID。
    *   **知识库URL（可选）**：用于指定卡片要添加到的特定知识库。

### 4.4 通用设置

*   **快捷键设置**：允许用户自定义触发“生成闪卡”的键盘快捷键。
*   **界面行为设置**：
    *   开关：是否在选中文本后自动显示悬浮工具栏。
*   **关于与隐私**：链接到项目主页和隐私政策说明。
