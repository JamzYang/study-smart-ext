# Chrome插件： StudySmart

## 核心价值定位

**AI 驱动的个性化知识点萃取工具**：将任意网络内容（文章、视频）转化为高质量、可复用的记忆卡片，并可导出到专业记忆平台。

## 用户群体

*   **语言学习者：** 英语（或其他语言）单词、短语、习语、语法、文化背景等。
*   **学生/研究人员：** 课程知识点、论文核心概念、专业术语、论据摘要等。
*   **专业人士：** 行业报告关键信息、技术概念、案例要点等。
*   **终身学习者：** 阅读新知、学习新技能时的要点捕捉。

## 需求讨论：核心功能与用户体验

### A. 核心功能 (Flashcard Generation)

1.  **内容选择与输入：**
    *   **文本：** 用户可以通过以下方式选择网页上的任意文本：
        *   **划词/框选：** 鼠标选中一段文本，在右键菜单或弹出的小浮窗中提供“生成闪卡”选项。
        *   **全段/全页处理：** 插件可以提供按钮，允许用户选择“当前段落”或“当前页面关键信息”进行分析（结合GPT的总结能力）。
    *   **视频：**
        *   **字幕文本：** 如果视频有字幕（如YouTube、Coursera等平台），插件应能自动获取或让用户粘贴字幕文本。用户可以：
            *   选中字幕中的任意一句话进行处理。
            *   点击字幕旁的“生成闪卡”按钮，处理该句。
            *   未来可以考虑与视频时间戳关联，点击闪卡可跳转到视频对应片段。
        *   **视频概括（高级）：** 用户选择视频某个时间段，插件（通过GPT）分析该段内容，生成总结性的闪卡。

2.  **GPT驱动的闪卡生成：**
    *   **多样化卡片建议：** 用户输入或选定内容后，插件不只生成一张闪卡，而是提供一个“建议列表”。例如：
        *   对于英文句子“I **cut corners** to finish the project on time.”，可以建议：
            *   **习语卡片：** 正面“cut corners”，背面“含义：走捷径，偷工减料；例句：...；引申：注重效率但也可能牺牲质量”。
            *   **词汇卡片：** 正面“project”，背面“含义：项目；同义词/近义词：undertaking, task；用法：...”。
            *   **语法卡片：** 正面“to finish... (不定式作目的状语)”，背面“解释：动词不定式可以用来表示目的或意图；例句：...”。
            *   **文化/背景卡片：** (若文本涉及) 关于某个概念的背景知识。
    *   **上下文保留：** 每张生成的闪卡背面或一个“来源”字段中，应能显示原始文本/句子或视频链接，方便用户回顾。
    *   **编辑与确认：** 在保存前，用户必须能够：
        *   **预览卡片：** 看到正面、背面和标签。
        *   **编辑卡片：** 修改卡片内容，调整措辞，增添补充说明。
        *   **选择性保存：** 从建议列表中选择感兴趣的闪卡进行保存。

3.  **闪卡内容结构：**
    *   **卡片类型：** 除了正反面，用户和GPT还可以定义闪卡的“类型”（例如：词汇、习语、语法、概念、摘要、问题解答等），便于后期筛选和管理。
    *   **标签（Tags）：** 自动生成与手动添加标签（如：英语、学习方法、项目管理、科技），用于分类和检索。
    *   **额外字段：** 如“例句”、“助记”、“引申意义”、“同义词/反义词”、“来源（文章URL或视频时间戳）”。这些可以灵活配置。

### B. 用户体验与工作流

1.  **便捷的触发方式：**
    *   **右键菜单：** 划词后，在右键菜单中提供“用GPT生成闪卡”。
    *   **悬浮按钮：** 划词后在选中内容附近弹出一个小浮窗，上面有“闪卡”按钮。
    *   **快捷键：** 定义快捷键触发当前选中内容的闪卡生成。
    *   **侧边栏：** 插件可以作为Chrome的侧边栏打开，始终可见，显示当前的闪卡列表和操作区。

2.  **插件界面设计：**
    *   **简洁直观：** 主要界面展示已保存的闪卡，操作区简洁明了。
    *   **结果呈现：** GPT生成结果在一个清晰的弹窗或侧边栏中呈现，便于比较和选择。
    *   **即时保存：** 看到满意的卡片可以一键添加到个人闪卡库。

3.  **闪卡管理：**
    *   **插件内存储：** 所有保存的闪卡应首先存储在插件内部。
    *   **浏览与搜索：** 用户可以在插件界面内浏览所有保存的闪卡，并支持关键词搜索、按标签、按来源URL筛选。
    *   **编辑/删除：** 用户可以随时编辑或删除已保存的闪卡。
    *   **集合（Collections）：** 用户可以将相关联的闪卡分组到不同的“集合”或“课程”中（如“英语核心词汇”，“AI学习笔记”）。

### C. 高级功能：自定义指令（Custom Prompts）- 核心差异化特性！

这绝对是此插件最强大的功能，能满足各种学习场景。

1.  **自定义 Prompt 编辑器：**
    *   用户可以输入自己的 Prompt，指导 GPT 如何分析文本并生成闪卡。
    *   **Prompt图标：** 用户可以为每个自定义Prompt设置一个直观的图标，该图标会显示在悬浮工具栏的快捷按钮上，便于快速识别。
    *   **示例 Prompt 1 (针对习惯性表达)：**
        ```
        请从以下文本中提取所有的习惯性表达（idioms/phrases），并为每个表达生成一张闪卡。
        闪卡格式要求：
        正面：{{习惯性表达}}
        背面：
        - 含义：{{含义}}
        - 例句（保持原文本中的例句或生成一个新的例句）：{{例句}}
        - 额外信息：{{如有需要，可添加来源、引申等}}

        文本：
        {{selected_text}}
        ```
    *   **示例 Prompt 2 (针对复杂概念解释)：**
        ```
        请从以下文本中提取一个核心概念，并为其生成一张解释性闪卡。
        闪卡格式要求：
        正面：{{核心概念名称}}
        背面：
        - 定义：{{概念的简洁定义}}
        - 关键特点/组成部分：{{关键属性的列表}}
        - 相关概念：{{与之关联的其他概念}}
        - 示例：{{具体案例}}
        - 思考问题：{{可启发用户进一步思考的问题}}

        文本：
        {{selected_text}}
        ```
    *   **支持占位符：** `{{selected_text}}` (表示用户选择的文本)、`{{video_transcript}}` (表示视频字幕) 等。未来可以考虑加入 `{{current_page_title}}`, `{{current_page_url}}` 等。

2.  **Prompt 预设与管理：**
    *   **保存与命名：** 用户可以将自定义的 Prompt 保存为预设（Preset），并为其命名（例如：“英语习语提取”，“科学概念解析”）。
    *   **快速选择：** 在生成闪卡时，用户可以在插件界面中快速选择一个已保存的 Prompt 进行调用。
    *   **预置 Prompt 库：** 插件可以提供一些默认的、高质量的 Prompt，如：
        *   通用词汇定义
        *   句子语法分析
        *   总结段落大意
        *   问题/答案对生成
        *   观点与反驳观点提取

3.  **GPT输出格式引导：**
    *   可以在Prompt中引导GPT按照某种结构化输出（如Markdown列表、JSON格式），方便插件解析和显示。这可以在技术层面解决，但需求是用户可以定制。例如，告诉GPT生成“正面：[内容]，背面：[内容]”的格式。

### D. 集成与导出

1.  **RemNote/Anki API 导出：**
    *   **认证：** 用户需要在插件中配置其 RemNote/Anki 的 API Key 或账户凭证。
    *   **选择性导出：** 用户可以选择性导出单张卡片、某个集合，或所有闪卡。
    *   **数据映射：** 插件需要将内部闪卡结构映射到 RemNote 的 Rem 类型或 Anki 的 Note Type。这可能需要用户在设置中进行简单的字段映射（例如：插件的“正面”映射到Anki的“Front”字段，“背面”映射到“Back”字段，“标签”映射到“Tags”字段）。
    *   **API 文档：** 依赖 RemNote/Anki 的开放 API 权限和文档支持。
    *   **双向同步（未来考虑）：** 高级功能，但如果能实现与RemNote/Anki的双向同步（即插件内的卡片更新，RemNote/Anki也更新；或反之），那就更强大了。但初期先专注单向导出。

2.  **通用导出选项：**
    *   **CSV 格式：** 用户可以导出闪卡为 CSV 文件，便于在其他表格软件中打开，或导入其他记忆平台。
    *   **JSON 格式：** 对于开发者或高级用户，提供 JSON 导出便于数据传输和再利用。

### E. 其他考虑

*   **模型提供商管理：**
    *   插件需要有一个专门的设置区域，让用户管理不同的AI模型提供商。
    *   **支持主流厂商：** 支持配置多家服务商，如 OpenAI, Gemini, Groq, DeepSeek 等。
    *   **配置字段：** 每个厂商都需要提供独立的`API Key`和`Base URL`输入框，以便用户使用官方或代理服务。
*   **成本估算：** 在生成闪卡时，可以显示预计消耗的tokens数量，让用户对API使用成本有所感知。
*   **错误处理：** 如果GPT API调用失败，能给出明确的错误提示（例如：API Key无效、请求超时、内容太长等）。
*   **隐私与安全：** 强调用户的数据（特别是其API Key）只在本地插件运行，不收集用户的选中内容。
*   **性能：** 生成和显示闪卡的速度要快，不影响浏览器日常使用。
*   **UI/UX 友好：** 整体界面应清晰、直观、易于上手，即使是普通用户也能轻松使用。

## 总结

这款插件的核心竞争力在于：**GPT驱动的智能提取** + **高度自定义的Prompt系统** + **便捷的Anki/RemNote集成**。

从最核心的需求开始：
1.  用户能选中网页/视频内容。
2.  能通过预设或自定义Prompt调用GPT生成多样化的闪卡建议。
3.  用户可以预览、编辑并选择保存到插件内部。
4.  插件内部能有效管理（浏览、搜索、编辑）这些闪卡。
5.  可以方便地导出到RemNote/Anki。
