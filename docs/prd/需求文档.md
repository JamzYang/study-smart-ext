# StudySmart 插件需求规格说明书

## 1. 概述

### 1.1 项目愿景 (Project Vision)
**AI 驱动的个性化知识点萃取工具**：将任意网络内容（文章、视频）转化为高质量、可复用的记忆卡片，并可导出到专业记忆平台。

### 1.2 目标用户 (Target Audience)
*   **语言学习者：** 英语（或其他语言）单词、短语、习语、语法、文化背景等。
*   **学生/研究人员：** 课程知识点、论文核心概念、专业术语、论据摘要等。
*   **专业人士：** 行业报告关键信息、技术概念、案例要点等。
*   **终身学习者：** 阅读新知、学习新技能时的要点捕捉。

### 1.3 核心竞争力
*   **GPT驱动的智能提取**: 利用大语言模型，从选定文本中智能生成多样化的闪卡建议。
*   **高度自定义的Prompt系统**: 用户可以创建和管理自己的Prompt模板，精准控制AI生成卡片的内容和格式。
*   **便捷的Anki/RemNote集成**: 与主流记忆软件无缝集成，简化学习工作流。

## 2. 详细功能需求

### 2.1 闪卡生成 (Flashcard Generation)

#### 2.1.1 内容输入
*   **文本选择**: 用户可通过鼠标划词/框选网页上的任意文本。
*   **视频字幕**: 插件能获取视频字幕文本（如YouTube）。用户可选定单句字幕或使用字幕旁按钮处理。
*   **全页/全段处理 (未来考虑)**: 允许分析整个段落或页面，并总结关键信息。

#### 2.1.2 触发方式
*   **悬浮工具栏 (Floating Toolbar)**: 选中文本后，在选区附近出现一个工具栏。
    *   **外观**: 横向、圆角，包含一系列代表不同Prompt的快捷按钮（图标+文字或仅文字）。
    *   **交互**: 点击按钮触发对应的卡片生成流程。鼠标移开或点击页面其他部分，工具栏自动消失。
*   **右键菜单**: 划词后，在系统右键菜单中提供"用StudySmart生成闪卡"选项。
*   **快捷键**: 支持自定义快捷键，触发生成流程。

#### 2.1.3 AI驱动的生成流程
1.  **触发**: 用户通过上述任一方式点击一个Prompt指令后，弹出**卡片生成面板 (Generation Panel)**。
2.  **自动执行**: 面板弹出后，立即使用用户选择的文本和对应的Prompt调用AI模型，无需二次点击。
3.  **界面展示**:
    *   **面板位置**: 可设计为页面右上角的模态框(Modal)或弹出窗口(Popup)。
    *   **输入区**: 显示用户选择的来源文本和当前使用的Prompt（可切换）。
    *   **加载状态**: 在等待AI响应时，显示加载动画和提示信息。
    *   **结果区 (卡片建议列表)**: AI返回结果后，以列表形式展示所有建议的闪卡。
        *   **预览与编辑**: 每张建议卡片都以"正面"和"背面"的形式清晰展示，且内容可直接点击编辑。
        *   **选择与舍弃**: 每张卡片前有复选框（默认全选），角落有"x"按钮，方便用户批量选择或单独舍弃不想要的卡片。
    *   **操作区**:
        *   **保存**: "添加到卡片库"按钮，将所有勾选的卡片保存至个人卡片库（默认为收件箱）。
        *   **错误提示**: 若API调用失败，显示清晰的错误信息。

#### 2.1.4 闪卡内容结构
*   **卡片类型**: 支持定义闪卡的类型（如：词汇、语法、概念、问题解答等）。
*   **标签 (Tags)**: AI自动生成或用户手动添加，用于分类检索。
*   **核心字段**: 正面、背面。
*   **额外字段**: 例句、助记、引申意义、同义词/反义词、来源URL或视频时间戳。

### 2.2 闪卡管理 (Flashcard Management)

通过点击浏览器工具栏的插件图标，打开**侧边栏 (Sidebar)**，即用户的个人卡片库。

#### 2.2.1 侧边栏界面布局
*   **左侧 - 集合列表**:
    *   一个可折叠的树状列表，显示所有卡片集合（文件夹）。
    *   **收件箱 (Inbox)**: 一个顶部的固定集合，所有新卡片默认保存于此。
    *   **用户集合**: 用户可自由创建、重命名、删除集合。
*   **右侧 - 卡片列表**:
    *   **顶部控制区**: 包括搜索框、筛选器（按标签、来源、同步状态）、批量操作按钮（移动、删除）和导出按钮。
    *   **卡片条目**: 以列表形式展示卡片。
        *   **内容**: 显示卡片正面内容、标签和来源网站favicon。
        *   **同步状态**: 用图标清晰标识（待同步、已同步、同步失败）。
        *   **交互**:
            *   **单击**: 展开卡片详情。
            *   **悬浮**: 显示编辑和删除图标。
            *   **多选**: 通过复选框进行批量操作。
            *   **拖拽**: 支持将卡片拖拽到左侧的集合中进行归类。
            *   **右键**: 提供快捷操作菜单。

### 2.3 高级功能：自定义Prompt
这是插件的核心差异化特性，通过**自定义Prompt管理器**实现。

#### 2.3.1 Prompt管理器界面
此界面整合在插件的"设置"页面中。
*   **左侧 - Prompt列表**:
    *   显示所有预置和用户自定义的Prompt。
    *   支持拖拽排序，决定其在悬浮工具栏和下拉菜单中的顺序。
    *   提供新建、复制、删除Prompt的操作。
*   **右侧 - Prompt编辑区**:
    *   **Prompt名称**: 输入框，名称会显示在UI上（如悬浮按钮）。
    *   **Prompt图标**: 提供图标选择器，为Prompt关联一个直观的图标。
    *   **在工具栏中显示**: 开关控件，决定此Prompt是否作为快捷方式出现在悬浮工具栏。
    *   **Prompt内容**: 大文本域，用于编写指令。
    *   **占位符提示**: 清晰列出所有可用占位符，如 `{{selected_text}}`。
    *   **操作按钮**: 保存或取消。

### 2.4 集成与导出

#### 2.4.1 导出平台设置
在插件的"设置"页面中，为每个支持的平台提供独立的配置面板。
*   **Anki 设置**:
    *   配置AnkiConnect的API URL和可选的API Key。
    *   **字段映射**: 连接成功后，能自动获取Anki的笔记类型和字段，允许用户将插件字段（正面、背面、标签等）映射到Anki字段。
*   **RemNote 设置**:
    *   配置API Key和User ID。
    *   可选的知识库URL。

#### 2.4.2 导出流程
*   **选择性导出**: 用户可在卡片库中选择单张、多张、或整个集合的卡片进行导出。
*   **状态反馈**: 导出后，卡片的同步状态会相应更新。

#### 2.4.3 通用导出选项
*   **CSV格式**: 便于在其他表格软件中打开。
*   **JSON格式**: 便于开发者或高级用户进行数据迁移。

## 3. 设置页面 (Settings Page)

设置页面是所有配置的中心枢纽，采用清晰的标签页导航结构。

### 3.1 AI模型设置
*   **多配置管理**: 允许用户创建和保存多个AI模型配置（如"公司用OpenAI"、"个人Gemini"），并可随时切换。
*   **配置详情**: 每个配置包含：
    *   **API提供商**: 下拉选择（OpenAI, Gemini, Groq等）。
    *   **API密钥**: 输入框。
    *   **自定义基础URL (Base URL)**: 可选，支持代理或私有化部署。
    *   **模型名称**: 指定使用的具体模型（如 "gpt-4-turbo"）。

### 3.2 Prompt管理
即 `2.3` 中描述的 **自定义Prompt管理器**。

### 3.3 导出平台设置
即 `2.4.1` 中描述的 **导出平台设置**。

### 3.4 通用设置
*   **快捷键设置**: 自定义触发卡片生成的键盘快捷键。
*   **界面行为设置**: 如"是否在选中文本后自动显示悬浮工具栏"。
*   **关于与隐私**: 链接到项目主页和隐私政策。

---

## 4. 非功能性需求

*   **性能**: 插件的响应速度要快，不影响浏览器日常使用。
*   **隐私与安全**: 用户的API Key等敏感数据必须安全地存储在本地，不上传至任何服务器。
*   **错误处理**: 在API调用失败、网络异常等情况下，向用户提供清晰、友好的错误提示。
*   **UI/UX**: 整体界面应简洁直观、易于上手，核心操作路径尽可能短。
